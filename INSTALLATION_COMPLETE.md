## 🔧 **CUSTOMIZATION OPTIONS**

### Change 3D Colors
Edit `HeroScene.jsx` or `Avatar3D.jsx`:
```javascript
color="#a78bfa"        // Change primary color
emissive="#7c3aed"     // Change glow color
```

### Adjust Animation Speed
```javascript
rotation.y += 0.002    // Increase/decrease 0.002
```

### Modify Parallax Intensity
```jsx
<Tilt
  tiltMaxAngleX={25}   // Increase for more tilt
  scale={1.05}         // Increase for more zoom
/>
```

See **DEVELOPER_REFERENCE.md** for more customization options.
